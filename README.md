# 가족 책도장

가족이 함께 쓰는 독서 기록 앱입니다. 도서관에서 빌린 책, 집에 있는 책, 전집을 기록하고 반납일·달력·배지·가족 순위를 보여 줍니다.
휴대폰과 태블릿에 앱처럼 설치해서 쓸 수 있습니다(PWA).

- 화면: GitHub Pages (이 저장소)
- 데이터: Firebase Cloud Firestore (무료 Spark 요금제)
- 가족 정보와 책 기록은 이 저장소가 아니라 Firebase에만 저장됩니다.

## 처음 설정하는 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어갑니다.
2. **프로젝트 추가** → 이름(예: family-books) → Google 애널리틱스는 꺼도 됩니다 → 만들기.

### 2. 익명 로그인 켜기
1. 왼쪽 메뉴 **빌드 › Authentication** → 시작하기.
2. **로그인 방법** 탭 → **익명** → 사용 설정 → 저장.

### 3. Firestore 데이터베이스 만들기
1. 왼쪽 메뉴 **빌드 › Firestore Database** → 데이터베이스 만들기.
2. 위치는 `asia-northeast3 (서울)`을 고릅니다. 프로덕션 모드로 만듭니다.
3. **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 **게시**합니다.

### 4. 웹 앱 등록하고 설정값 넣기
1. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정** → 일반 → 내 앱 → 웹(`</>`) 아이콘.
2. 앱 닉네임을 적고 등록합니다(호스팅 설정은 체크하지 않아도 됩니다).
3. 화면에 나오는 `firebaseConfig`의 값들을 `firebase-config.js`에 옮겨 적습니다.
   이 값들은 웹 앱에 원래 공개되는 값이라 저장소에 올려도 괜찮습니다. 데이터 보호는 3번의 규칙이 맡습니다.

### 5. GitHub Pages 켜기
저장소 **Settings › Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
몇 분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 열립니다.

## 태블릿·휴대폰에 설치하기
- **삼성 인터넷:** 주소를 연 뒤 주소창의 설치 아이콘을 누르거나, 메뉴 › 현재 페이지 추가 › 홈 화면.
- **크롬:** 메뉴(⋮) › 앱 설치 또는 홈 화면에 추가.
- 처음 열 때 가족 코드를 넣고 쓸 사람을 고릅니다. 아이 기기라면 설정에서 **부모 잠금 번호**를 걸어 두세요.

## 예전 Claude 앱에서 옮겨오기
1. Claude의 가족 책도장 › 설정 › 데이터 옮기기 › **파일로 내보내기**(또는 복사해서 내보내기).
2. 새 앱 첫 화면 › **예전 앱에서 옮겨오기** › 파일을 고르거나 붙여넣기 › 가져오기.
   가족 코드와 책이 그대로 옮겨지고, 표지는 작게 줄여서 저장됩니다.

## 백업
Firebase의 예약 백업은 유료(Blaze) 요금제에서만 됩니다. 대신 앱에서 직접 백업합니다.
- 부모 프로필 › 설정 › 백업 · 데이터 옮기기 › **백업 파일 저장** (한 달에 한 번 권장)
- 마지막 백업이 한 달을 넘으면 책장 위에 알림이 뜹니다.
- 되살릴 때는 같은 곳의 **가져오기**에 백업 파일을 넣습니다.

## 파일 설명
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `firebase-config.js` | Firebase 설정값 |
| `firestore.rules` | 데이터베이스 보안 규칙(Firebase 콘솔에 붙여넣기) |
| `manifest.webmanifest`, `icon-*.png` | 설치용 앱 정보와 아이콘 |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
